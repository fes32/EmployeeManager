
Employee Manager
================

Описание
--------
Приложение для управления учетными данными сотрудников.
Реализовано на C#, Windows Forms и SQLite.

Функциональность
----------------
- Просмотр списка сотрудников.
- Создание сотрудника.
- Просмотр подробной информации.
- Редактирование данных.
- Удаление сотрудника с подтверждением.
- Проверка корректности вводимых данных.

Требования
----------

Для запуска опубликованной версии:
- Windows x64.
- Установка отдельного .NET Runtime не требуется

Запуск из исходного кода
------------------------
1. Откройте файл решения в Visual Studio.
2. Восстановите пакеты NuGet.
3. Соберите решение.
4. Запустите приложение.

Запуск опубликованной версии
----------------------------
1. Откройте папку публикации.
2. Запустите EmployeeManager.exe.

Хранение данных
---------------
База данных создается автоматически при первом запуске.

Путь к базе данных:
%LOCALAPPDATA%\EmployeeManager\employees.db

Удаление файла базы данных приведет к потере сохраненных
данных сотрудников. Перед удалением сделайте резервную копию.

Примечание
----------
Не удаляйте файлы из папки публикации, необходимые для
работы приложения.
